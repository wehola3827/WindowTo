常见问题解答 Frequently Asked Questions

为什么 WindowTo 需要“辅助功能”权限？ Why does WindowTo require "Accessibility" permission?

由于 macOS 的安全沙盒限制，任何用于跨应用调整窗口大小 and 位置的系统工具，都必须在系统设置中获得“辅助功能（Accessibility）”授权。WindowTo 仅会利用此权限来实现窗口排版逻辑，绝不会以此收集、读取或传输您的任何个人屏幕或键盘输入信息。 Due to macOS security sandbox restrictions, any system utility designed to resize and reposition windows of other applications must be granted "Accessibility" authorization. WindowTo only utilizes this privilege to implement window layout actions, and will never collect, read, or transmit your screen contents or keystrokes.

运行有什么系统版本限制？ What are the system requirements?

WindowTo 深度适配了 macOS 的底层 API。为了获得最极致、流畅的窗口排版体验，我们建议您的系统运行在 macOS 12.0 或更高版本。

WindowTo is deeply optimized for native macOS APIs. To ensure the smoothest window management experience, we recommend using macOS 12.0 or later.
